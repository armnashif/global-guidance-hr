Deployment Steps

  1. 1

    Open Your Google Sheet

    Open Google Sheet
  2. 2

    Go to Extensions → Apps Script

    This will open the Apps Script editor in a new tab

  3. 3

    Delete Existing Code

    Select all (Ctrl+A) and delete any existing code

  4. 4

    Copy the Complete Script

    Or scroll down and manually copy the code

  5. 5

    Paste in Apps Script Editor

    Paste the entire script (Ctrl+V)

  6. 6

    Save the Project

    Click File → Save or press Ctrl+S

  7. 7

    Deploy as Web App

    • Click "Deploy" → "New deployment"
    • Click the gear icon ⚙️ next to "Select type"
    • Choose "Web app"
    • Description: "Umair Portal Integration"
    • Execute as: "Me"
    • Who has access: "Anyone"
    • Click "Deploy"
  8. 8

    Authorize the Script

    Click "Authorize access" and follow the prompts

  9. 9

    Copy the Web App URL

    After deployment, copy the URL (it ends with /exec)

    https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
  10. 10

    Configure in Portal

    Go to System Settings

    System Config → Google Sheets Integration → Configure
