Troubleshooting

Issue: Configure button doesn't open the modal

✅ This is now fixed! The page was rebuilt and the button works correctly.

If you still experience issues, try clearing your browser cache or doing a hard refresh (Ctrl+F5 or Cmd+Shift+R).

Issue: Test Connection fails

Make sure:

  • • Apps Script is deployed as Web App
  • • Deployment URL is complete (includes /exec)
  • • Access is set to "Anyone"
  • • You authorized the script when deploying

Issue: Portal shows no data

Check that:

  • • Staff tab has Umair's record (Email: umair@globalguidance.com)
  • • Applications/Offers have Handler column matching "UMAIR001" or "Umair"
  • • Required tabs exist: Staff, Attendance, Applications, Offers
