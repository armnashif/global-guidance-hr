Quick Setup Guide

  1. 1 Open the Google Sheet above (click "Open Sheet")
  2. 2 Click Extensions → Apps Script in the menu
  3. 3 Delete any existing code and paste the Apps Script code
  4. 4 Click Deploy → New deployment
  5. 5 Select type: Web app
  6. 6 Set Execute as: Me, Who has access: Anyone
  7. 7 Click Deploy and copy the Web app URL
